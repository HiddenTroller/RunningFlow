# 공식 자료 자동 대조

## 사용
사진 분석 → 2번 제품 선택 → 공식 자료 대조 → 명확하면 계산 목록에 바로 적용.
공식 함량·기준이 불명확하거나 사진/공식 자료와 충돌하면 보완 확인란이 열립니다. 확인용으로 찾은 전체 성분, mg 함량, 함량 기준, 출처 URL, 근거 원문을 미리 채웁니다. 해당 자료를 확인한 사용자가 검토자·확인일·대조 확인을 완료하면 기존 verified_products.json에 저장하고 적용합니다.
선택 전에 자동으로 제품을 확정하거나 복용 수량을 채우지는 않습니다.

## 자동 조회 범위
의약품안전나라의 고정 공식 HTTPS 도메인에서 품목기준코드로 제품 상세 페이지를 조회합니다.
https://nedrug.mfds.go.kr/pbp/CCBBB01/getItemDetail?itemSeq=품목기준코드
제품명·업체명·품목코드가 API와 모두 일치해야 사용합니다. 공식 페이지의 전체 주성분 이름과 API 성분 코드, 분량, 단위, 기준수량을 대조합니다. 원문 문구·출처·조회시각·페이지 해시를 계산 기록에 남깁니다.
명확한 기존 API 결과가 사진과 모두 일치하거나 사용자가 저장한 검토 보완값이 있으면 그것을 우선하며 불필요한 공식 페이지 호출은 생략합니다.
공식 페이지 응답은 메모리에 15분, 최대 100품목 캐시합니다. 실패는 캐시하지 않습니다. 새로고침만으로 외부 분석·조회는 하지 않습니다.

## 보류 조건
품목 식별정보 불일치, 성분 목록 차이, 같은 층의 중복, 값 충돌, 기준 불명, 합쳐진 셀, IU 등 직접 환산 불가 단위, 성분 환산/비고 정보, 사이트 연결 실패는 확인 필요로 처리합니다.
층별 표는 각 층의 명시된 숫자와 공유되는 함량 기준이 확인된 경우에만 합계 후보를 만듭니다. 기존 API의 층별 숫자가 다르면 확인 없이 적용하지 않습니다. 숫자가 비어 있는 것과 값 충돌은 구분합니다.
공식 API 자체가 반환하지 않은 성분 코드를 AI가 만들지 않습니다. 성분 코드 매핑을 정확히 확인하지 못하면 보류합니다.
이 기능은 검색엔진의 임의 결과나 블로그에서 약 함량을 추측하지 않습니다. 제조사 PDF·이미지 설명서 자동 인식은 현재 범위에 포함하지 않으며 표 구조를 읽지 못하면 직접 확인합니다.

## 계산과 기존 정책
확인된 함량은 mg으로 계산하고 정·캡슐·포·mL의 분모는 보존합니다. 공식 자료 대조는 제품 함량만 확인하며 최대량 미초과로 복용 가능 여부를 판단하지 않습니다.
Studio 설정 15번 고정, 제품 선택 메뉴, 사용자 수량 입력, e약은요·최대투여량 참고 조회는 유지합니다.
테스트: Python 144개, JavaScript 화면 흐름 통과. 실제 의약품안전나라 타이레놀 성분 표에서 층별 추출을 확인했습니다. 자동 대조 결과는 사용자 검토 완료 기록으로 위장하지 않으며 계산 근거에 별도로 남깁니다.


## 공식 성분표 우선 정책 (2026-10-16 사용자 요청)
품목코드·제품명·업체명, 전체 유효성분 이름 및 코드와 성분표의 수량·단위를 검증한 경우 공식 페이지의 성분표를 API 함량/층별 값보다 우선 적용합니다. API와의 차이는 api_differences, 원래 API 자료는 original_official에 보존합니다.
성분표 자체의 중복·불명확한 단위·병합 셀·다른 품목·성분 목록 불일치는 계속 차단합니다. 사진과 공식 성분의 불일치 검토도 유지합니다. API 일부 반환 경고는 전체 목록 검증 문제이므로 계속 확인이 필요합니다.
