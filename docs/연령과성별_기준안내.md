# 연령·성별 비교 지원 범위

아동·청소년·성인 모두 입력 수량의 성분 합산과 중복 확인을 지원합니다. 분류만으로 실제 나이나 복용량을 추정하지 않습니다.

용량 기준 비교는 verified_rules.json에 출처·검토자·검토일·reviewed가 등록된 규칙만 사용합니다. 현재 이 파일은 비어 있으므로 실제 의약품의 연령별 최대량 판정은 아직 제공되지 않습니다. 테스트의 수치는 가상 값입니다.

규칙 선택 조건: population(child/adolescent/adult), sex(any/male/female, 생략 시 any), min_age_years 이상·max_age_years 미만, min_weight_kg 이상·max_weight_kg 미만. 아동·청소년 규칙은 품목코드 범위와 최소·최대 만 나이 조건이 필수입니다. 필요한 값이 없으면 미판정입니다. 아동·청소년에게 성인 규칙을 대입하지 않습니다. limit_mg만 지원하고 임의 mg/kg 공식을 만들지 않습니다. 역가·IU는 mg 기준과 비교하지 않습니다.

알 수 없는 추가 조건이 있는 규칙은 자동 적용하지 않습니다. 임신·수유·간신장 기능·투여 경로·제형별 조건을 성별만으로 추정하지 않습니다. 조건이 복잡한 자료는 별도 검증을 거쳐 구현해야 합니다.
