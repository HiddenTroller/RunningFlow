# 여러 사진 분석

사진을 한 번에 최대 20장 선택하며 장당 10MB 이하 JPG/PNG/WEBP를 지원합니다. 사진마다 제품 한 종류가 보이도록 촬영합니다. 서로 다른 약 여러 개가 한 사진에 있는 경우 분리 인식을 보장하지 않습니다.

각 사진을 기존 Studio 분석 API에 순서대로 전달하며 사진별로 API 사용량이 발생합니다. 후보가 유일한 정확 검색 결과이면 자동 추가합니다. 후보가 여러 개이거나 유사 검색이면 파일명·사진 번호별로 직접 선택합니다. 같은 제품 코드가 이미 목록에 있으면 중복 추가하거나 수량을 자동 증가시키지 않습니다. 수량은 사용자가 입력합니다.

분석 실패는 해당 사진에만 표시하고 다음 사진을 계속 처리합니다. 사진별 후보는 순서와 관계없이 선택할 수 있습니다. 계산 목록은 최대 30개입니다. 함량 확인이 필요한 제품은 기존 계산 보류 규칙을 따릅니다.

사진 내용은 브라우저 세션 저장에 넣지 않습니다. 사진 파일명·후보 제품명·서버 확인 ID와 처리 상태만 저장합니다. 새로고침으로 진행 중 업로드가 중단된 경우 해당 사진을 다시 선택해야 합니다. 서버가 재시작되거나 30분이 지나 선택 후보 ID가 만료되면 미선택 사진을 재분석해야 합니다. 이미 목록에 추가된 제품은 기존 공식 정보 다시 확인 기능을 사용할 수 있습니다.
