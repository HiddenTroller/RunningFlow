# 추가 식약처 API 연결 안내

## 설정 위치
바탕화면 learningflow-med-python-revised 폴더의 .env를 편집합니다.

두 API를 각각 공공데이터포털에서 활용신청해 승인받으세요.
- 의약품개요정보(e약은요): https://www.data.go.kr/data/15075057/openapi.do
- 의약품 성분별 1일 최대투여량 정보: https://www.data.go.kr/data/15098095/openapi.do

승인 후 다음 두 값을 true로 바꾸세요.
```
MFDS_EASY_ENABLED=true
MFDS_MAX_DOSE_ENABLED=true
```
같은 계정의 기존 MFDS_SERVICE_KEY를 사용한다면 아래 두 키 항목은 비워도 됩니다.
별도 키를 쓰려면 일반 인증키(Decoding)를 입력하세요.
```
MFDS_EASY_SERVICE_KEY=
MFDS_MAX_DOSE_SERVICE_KEY=
```
키는 채팅으로 보내거나 공유용 파일에 넣지 마세요. 승인되지 않은 API는 false로 유지할 수 있습니다.
서버를 재실행할 필요 없이 설정 저장 후 제품을 새로 선택하면 읽습니다. 화면 새로고침 시 기존 목록은 지워집니다.

## 사용 흐름
1번 사진 분석 → 2번 제품명 선택 → 공식 성분으로 계산 목록에 적용 → 직접 수량 입력 → 성분 합산.
각 제품의 ‘추가 공식 API 정보’를 펼치면 e약은요의 사용법·주의사항·상호작용과 성분별 최대투여량 원본을 확인할 수 있습니다.
API 상태 disabled는 미사용, error는 인증·조회 실패, unconfirmed는 정확한 품목·전체 기준 미확인입니다.
새 API는 제품을 선택할 때만 조회하며 새로고침만으로 외부 API를 호출하지 않습니다.
후보별 최대 10개 대조 정책은 기존과 동일합니다. 추가 API는 선택 제품 1회당 e약은요 1회와 서로 다른 성분코드당 최대량 1회를 호출합니다(활성화된 경우).

## 함량 계산 범위
제품의 1정·1캡슐·기준 mL당 함량은 기존 의약품 제품 허가정보에서만 가져옵니다.
주성분 함량이 누락되었을 때, 제품 상세 MATERIAL_NAME이 단일 성분·단일 기준이고 성분명이 정확히 일치하면 명시된 함량·단위·기준을 보완합니다. 원문을 계산 근거에 보존합니다.
여러 성분·층별 성분·중복 행·불명확한 기준이나 충돌은 추측하지 않습니다. 타이레놀 8시간 이알서방정의 층별 누락·충돌은 이번 추가 API만으로 해결되지 않으며 계산 보류가 유지될 수 있습니다.
e약은요의 사용법 문장을 성분 함량으로 사용하지 않습니다.
성분별 1일 최대투여량은 제형·투여경로 등 적용 조건 검증 전 참고값이며, 제품 함량을 채우거나 자동으로 ‘검증 완료’ 규칙에 등록하지 않습니다. 기준 비교는 기존 verified_rules.json의 검토 완료 규칙만 사용합니다.
복용 가능 여부는 판단하지 않습니다.

## 검증
Python 테스트 120개 및 JavaScript 화면 흐름 검사 통과. 신규 API는 가짜 응답으로 검증했고 실제 계정의 신규 API 승인·실응답은 아직 확인하지 않았습니다.
Studio 설정 15번 고정 정책은 유지합니다.
