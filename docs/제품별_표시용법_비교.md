# 제품별 표시 용법 비교

근삿값이나 추정 안전 최대량을 만들지 않습니다. 서버가 받은 품목별 허가 용법 원문에서 단일 1회 수량·단위와 하루 횟수가 명확한 경우만 표시 용법과 비교합니다.

- 원문의 명시 나이 조건을 먼저 검사합니다.
- 성인 용법만 있고 정확한 시작 나이가 없는 경우, 서비스 지원 범위를 만 19세 이상으로 제한합니다. 이는 보편적인 의학적 성인 기준이 아닙니다.
- 명시된 복용 금지 연령에 해당하면 별도로 표시합니다.
- 표시 용법 상한(1회량 상한 × 하루 횟수 상한)과 원문에 직접 기재된 최대량을 구분합니다. 전자는 모든 성분에 통하는 최대 허용량이 아닙니다.
- 단위가 다르거나 나이 조건·용법이 여러 개이면 미판정입니다. 병 단위를 mL로 추정하지 않습니다.
- 성분 합산 기준이 없더라도 제품별 용법 비교는 별도로 제공합니다. 개별 제품 미초과가 병용 안전을 뜻하지 않습니다.
- 복용 간격·개인 질환·임신·수유·다른 복용약은 판단하지 않습니다. 표시 용법 대비 초과량은 줄여 먹을 양을 추천하는 수치가 아닙니다.
