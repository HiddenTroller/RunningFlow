# 성분 공통 합산 비교

2026-10-16 확인: 식약처 의약품안전평가과의 ‘감기약 먹을 때 한번 더 확인하세요!’(2016-01-07)는 아세트아미노펜 성인 하루 4,000mg 초과 금지와 감기약·두통약·진통제의 중복 함유 확인을 안내합니다.
공식 출처: https://impfood.mfds.go.kr/CFBBB02F02/getCntntsDetail?cntntsSn=281811

현재 적용 범위: 공식 성분코드 M040353, 일반 질량 mg, 하루 총수량 모드, 서비스 지원 범위 만 19세 이상. 특정 품목 목록에 제한하지 않는 성분 공통 기준입니다. 아동·청소년이나 성분코드가 다른 원료에 일반화하지 않습니다.

품목 전용 기준이 모든 기여 제품을 포함하면 전용 기준을 우선하고, 그렇지 않으면 적용 가능한 성분 공통 기준을 사용합니다. 서로 다른 일반 기준이 충돌하면 미판정입니다. 1회 모드에 하루 기준을 적용하지 않습니다. 제품별 표시 용법은 별도로 비교하며 4,000mg 미초과가 모든 제품의 용법 미초과나 병용 허가를 뜻하지 않습니다.

간질환·음주·임신·개인 상태·복용 간격 등은 평가하지 않습니다. 이 규칙은 공식 안내를 수치로 대조한 것이며 의료전문가가 검토한 개인 맞춤 처방이 아닙니다. 다른 성분은 합산 적용을 뒷받침하는 출처와 조건이 확보된 경우에만 추가해야 합니다.
