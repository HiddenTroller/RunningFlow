# 공식 함량 자동 적용 지원 범위

공식 품목코드·제품명·업체명과 전체 성분 목록을 확인한 뒤 자동 적용합니다. 모든 의약품을 무조건 지원한다는 의미는 아닙니다.

- 질량: g·mg·μg를 mg으로 환산합니다.
- IU: IU 그대로 계산하며 mg으로 변환하거나 mg 최대량과 비교하지 않습니다.
- 역가: 역가 질량으로 표시하고 일반 질량과 별도 집계합니다.
- 환산 성분: 원료 성분명·원료량을 합산하며, “아스코르브산으로서 150mg” 같은 환산 표시는 별도로 보존·표시합니다. 환산 성분으로 재매핑하거나 원료량에 더하지 않습니다.
- 기준: 정·캡슐·포·mL·g·매·개·회. 1병(30mL) 중은 30mL 기준입니다.
- 내수/수출: 공식 페이지의 전체 성분표와 API의 전체 성분 목록이 동일한 경우에만 중복 행을 제외합니다.

자료 누락, 네트워크 실패, 공식 자료 간 충돌, 알 수 없는 단위·비고, 서로 다른 처방은 계속 확인이 필요합니다. 성분명만 보고 염형·원료와 환산 성분의 동등성을 추정하지 않습니다. IU·역가는 mg 전용 수동 보완 입력란에서 편집하지 않습니다.

예: 이가탄에프캡슐의 제피아스코르브산 156mg과 아스코르브산 환산량 150mg은 다른 값입니다. 현재 원료 성분 기준으로 합산하고 환산 문구를 함께 표시합니다.
